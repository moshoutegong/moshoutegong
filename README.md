### 你好，我是魔兽特工 👋

一个喜欢折腾的魔兽玩家。平时做《魔兽世界》插件的**汉化、修复与客户端适配**，也整理 Project Ascension（飞升）的中文资料，让查技能、配天赋、找装备更方便。

游戏之外，也做些实用小工具、小游戏，偶尔给这只 Doge 添几张新贴画。

[B 站：魔兽特工](https://space.bilibili.com/374737088) · [全部仓库](https://github.com/moshoutegong?tab=repositories) · [Doge 贴画集](https://github.com/moshoutegong/DogeIcons)

### 🧭 游戏资料与任务助手

- **[COA 中文资料站](https://github.com/moshoutegong/coa-website)** — 21 个职业、70 个专精的天赋模拟器和双语技能图鉴，核对并统一技能与天赋译名。
- **[世界铸造简中资料](https://github.com/moshoutegong/Worldforged-data-CN)** — 整理物品拾取点位、装备升级路线与数据出处，方便查找和对照。
- **[CoA 任务助手](https://github.com/moshoutegong/coa-questie-CN)** — Questie-X 的 CoA 兼容整合包，提供任务标记、追踪与导航。
- **数据整理与留存**：[Ascension 数据集](https://github.com/moshoutegong/ascension-data-CN) · [离线数据库存档](https://github.com/moshoutegong/AcensionOfflineDatabase) · [QuestieDB](https://github.com/moshoutegong/QuestieDB-CN) · [Ascension 任务数据库](https://github.com/moshoutegong/Questie-X-AscensionDB-CN)

### 🐕 魔兽之外的小作品

- **[Doge 软件小站](https://github.com/moshoutegong/Dogeweb)** — 汇集 DogeFetch、DogeGif、DogeRecord 等工具的介绍与下载入口。
- **[DogeIcons](https://github.com/moshoutegong/DogeIcons)** — 自己做着玩的柴犬贴画，收集各种表情、探险造型和变装。右上角的招手狗狗就来自这里。
- **[宝石小屋](https://github.com/moshoutegong/baoshi-house)** — 为纪念小鹦鹉「宝石」做的学习养宠小游戏，答题赚鸟粮，喂养、装扮，再一起闯解谜关卡。

这里既有自己的作品，也有基于开源项目的汉化、适配与整理。感谢原作者和社区贡献者；各项目的来源与致谢见对应仓库。
