### 你好，我是魔兽特工 👋

我做《魔兽世界》插件汉化，也整理 Project Ascension 的中文游戏资料，方便玩家查技能、配天赋、找装备。

- **[COA 中文资料站](https://github.com/moshoutegong/coa-website)** — 21 个职业、70 个专精的天赋模拟器和中英双语技能图鉴，统一了技能与天赋译名。
- **[世界铸造简中资料](https://github.com/moshoutegong/Worldforged-data-CN)** — 整理装备升级路线、物品拾取坐标和中英名称，支持按物品 ID 或地图查询。
- **[宝石小屋](https://github.com/moshoutegong/baoshi-house)** — 为了纪念我的小鹦鹉「宝石」做的养成小游戏。可以答题赚鸟粮、喂养、装扮，再带它去解谜。
